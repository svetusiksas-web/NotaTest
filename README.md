# NotaTest

Рабочий frontend-MVP сервиса для создания и прохождения тестов по сольфеджио и музыкально-теоретическим дисциплинам. Интерфейс и данные полностью работают в браузере: преподаватель создаёт и публикует тест, ученик открывает публичную ссылку, проходит задания, а результат появляется в журнале.

## Стек

- React 19 + TypeScript
- Vite
- React Router
- Lucide Icons
- CSS design system без UI-фреймворка
- `localStorage` через изолированный service layer

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Возможности MVP

- кабинет преподавателя, библиотека тестов и журнал результатов;
- редактор метаданных и пяти типов заданий: один/несколько вариантов, короткий ответ, сопоставление, порядок;
- автоматическое сохранение черновика и публикация по уникальному slug;
- заметный массовый импорт из текста Word, Google Docs или ChatGPT;
- массовая загрузка изображений и аудио с привязкой к вопросам по порядку;
- вставка изображений из буфера обмена в окне импорта;
- preview, замена и удаление медиа в редакторе;
- сохранение нераспознанных фрагментов для ручного исправления;
- публичная адаптивная страница ученика;
- строгая автоматическая проверка, баллы, проценты и оценка;
- подтверждение удаления и отправки работы;
- демо-тест «Сольфеджио — Интервалы».

## Формат массового импорта

Вопросы отделяются пустой строкой. Варианты начинаются с `-`, `•`, `*` или буквы. Правильный ответ указывается отдельной строкой. Несколько ответов разделяются запятой.

К тексту можно выбрать сразу несколько JPG/PNG/WEBP и MP3/WAV/M4A/OGG. Файлы каждого типа распределяются по вопросам по порядку: первое изображение и первое аудио относятся к первому вопросу, вторые — ко второму. Изображения также можно вставлять из буфера обмена. В локальном режиме рекомендуется использовать небольшие файлы: браузерное хранилище ограничено.

```text
1. Какой интервал содержит 5 ступеней?
- Терция
- Кварта
- Квинта
Ответ: Квинта

2. Назовите обращение трезвучия с терцией в басу.
Ответ: секстаккорд; 6
```

## Структура

```text
src/
  components/      общие элементы интерфейса
  data/             демонстрационные данные
  lib/              парсер, scoring и утилиты
  pages/            экраны преподавателя и ученика
  services/         слой хранения и интеграционные заглушки
  types/            доменные TypeScript-типы
```

UI не обращается к `localStorage` напрямую. `testService` и `resultService` можно заменить Supabase-реализациями без изменения страниц. Предлагаемые таблицы: `tests`, `questions`, `options`, `matching_pairs`, `ordering_items`, `attempts`, `answers`.

Для Telegram оставлена серверная заглушка `telegramService`. Токен нельзя добавлять в Vite-переменные или клиентский код: будущая отправка должна выполняться Edge Function или другим backend-сервисом с secret-хранилищем.

## Деплой

Проект можно развернуть как Vite SPA на Vercel, Netlify или Cloudflare Pages. Команда сборки — `npm run build`, каталог публикации — `dist`. Для прямых переходов по `/test/:slug` настройте SPA fallback на `index.html`.
